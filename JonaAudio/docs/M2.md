## Resource policy and limits

80 tracks and 125 MiB per encoded file remain intake limits. Default decoded PCM budget: 128 MiB; historical absolute upper ceiling: 256 MiB (not used as a phone guarantee). Analysis-window copies: 24 MiB; worker scratch estimate: 8 MiB; total known allocation budget: 192 MiB. Region/export placeholders for later milestones: 16/64 MiB. One native decode in flight; one full PCM owner retained only while queued work can reuse it; compact results only at idle. WAV source metadata is inspected with a 64 KiB read. Non-WAV/unknown metadata is explicitly uncertain and uses the smaller-file path; native decoding still requires whole-file allocation.

Reference allocation model, not measurements: iPhone 16 Pro Safari and MacBook Pro M4 Pro Safari/Chromium, 3-minute stereo source decoded at requested 44.1 kHz: 63,504,000 PCM bytes (~60.6 MiB). With an assumed 20 MiB encoded source, maximum 24 MiB input-window copies and 8 MiB worker scratch, known peak estimate ~112.6 MiB. Native decoder, browser and garbage-collection overhead remains unknown. Actual decoded rate/channels/array size are checked after native decode. Neither device was available for a physical measurement.

Quick inspects up to five candidate 12-second windows and analyzes up to three usable windows spread over time. Deep allows up to five 24-second windows, including lower-level nonzero audio. Exact copied ranges are recorded. Strongest sampled-energy channel supplies the mono analysis copy, avoiding opposite-polarity cancellation. Quick's sparse 1,200-bucket overview samples 16 points per bucket/channel: brief peaks may be missed; this is not an editing waveform or a full peak scan. M4 still owns detailed waveform/region export.

Key/tempo thresholds are provisional heuristics, not accuracy probabilities. The 105–175 BPM preference is removed. Resampling uses a 32-tap windowed-sinc filter with 64 fractional phases and records the engine version. Spectrum errors do not clear key/BPM. Existing level-metric definitions remain unchanged until M5.

Ruling: capability-specific scans can share one decode while queued; idle PCM is released. Decode failures/refusals are cached for the source revision so sibling jobs do not repeat expensive native allocations; explicit Retry clears that refusal. Force reanalysis retains previous musical results/ranges until replacements arrive. Region-boundary edits invalidate only that region's computed results and prevent old worker replies from holding the queue open.
