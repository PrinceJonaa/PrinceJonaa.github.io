# JonaAudio M3 — tuning preparation checkpoint

Spec: https://app.notion.com/p/3f7adfe90e7081a8a77de6478ba6d0ef
Scope: JA-09 note mask/reference keyboard and JA-10 tuning handoff. Same M1–M2 branch and PR. Broad QA remains M6; no deployment.

Plan: tuning-model.js owns pitch-class masks, scale/enharmonic/scientific names, frequency math, validation and copy text. tuning-state.js resolves local or explicitly inherited references and applies musical commands through store.js. tuning-view.js provides target/reference scope, tonic/major/natural-minor/custom notes, spelling and assumed/user-chosen A reference, alternatives, Copy/Share fallback and audition. reference-tones.js generates short sine notes or ascending sets and releases its context. Existing audio-service.js owns source audition; source play/pause/change, note Stop, backgrounding and tool changes stop tones predictably.

Musical contract: scale masks use pitch classes 0–11. A changed note becomes Custom and records the starting scale. Manual tonic/mode/mask choices never rewrite the detected key, and analysis/correction/layout/track changes do not overwrite them. Unedited/following setups refresh from the effective reference key. Explicit reference selection labels inheritance and keeps local region estimates unavailable when appropriate. Changing reference preserves manual decisions; Use reference key explicitly replaces those decisions. Reference source/range revisions are retained and stale references are labeled for review. A=440 is assumed until the user changes it; no audio measurement is claimed.

Manual setup works without importing or successfully analyzing audio. Empty note sets disable Copy/scale audition, while individual chromatic reference keys remain usable. Major/natural minor/custom and enharmonic spelling are distinct from pitch identity. Scale spelling handles diatonic accidentals such as E♯/B♯; scientific octave labels also preserve the sounding pitch (B♯3 = C4, C♭5 = B4).

Reference notes pause source playback and stop metronome/other tones. Source audition can use the chosen backing track/range without changing the track whose tuning setup is being edited; the mini-player names the actual playback source or reference tones. Range source audition uses media seeking, not sample-accurate looping. Actual loops remain M4.

No vocal contour, real-time pitch correction, proprietary plug-in presets, retune speed, formants or independent pitch/time processing are included. No persistence claim across reload for tuning decisions yet: M5 owns versioned session recovery. The current tab retains per-track/per-region/manual setups.
