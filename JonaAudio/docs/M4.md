# JonaAudio M4 — regions, suggestions, loops and WAV

Spec: https://app.notion.com/p/3f7adfe90e7081a8a77de6478ba6d0ef
Scope: JA-11, JA-12 and JA-13. Same draft PR/branch as M1–M3; no deployment. Broad browser/listening/device/export-corpus QA remains M6.

## Implementation plan and return

- sample-model.js / store.js: seconds/mm:ss parsing, frame-bound resolution, minimum two frames, meter/bar math, explicit anchor and snap, labels/fades and 30-edit session-local undo. Boundary edits invalidate scoped estimates; fades invalidate audio preparation; musical/grid edits mark derived suggestions stale. Stored region revisions remain monotonic through undo. No automatic resnap of a saved selection.
- sample-view.js: dedicated Sample tool with source overview, visible handles, numeric/set-in/out/nudge paths, per-track zoom/pan, source min/max detail, meter/tempo/anchor/snap and fades, zero assist, candidate preview/use/favorites/source order, preparation/cancel and fresh Share/Download/sidecar actions. A cancelled boundary drag discards its draft; one committed drag is one edit.
- jobs.js / worker.js / sample-candidates.js: optional 250 ms energy/onset/chroma feature scan in disposable chunks of at most 4 MiB. Strongest sampled-energy channel is explicit. Coarse maps are compact and reranking does not decode again. Candidate pool <=256; up to eight results, 1/2/4/8 bars with confirmed usable anchor or seconds-based lengths; four provisional ranking families, recorded reasons/weights/missing terms, silence rejection, IoU >0.65 suppression and neighborhood diversity. Favorites reorder only the current session.
- sample-dsp.js / resample.js: common stereo zero-boundary search within +/-5 ms; prepared source frames and common linear fade envelope; selected-region min/max pyramid with a 32-frame base and aggregated levels. The sparse full-source Quick overview remains separate. Shared resampling implementation extracted; engine version jona-dsp-2.1.0.
- sample-service.js / loop-player.js / audio-service.js: prepared region buffers use the audio clock at 1x. Source/tone/metronome ownership is coordinated through transport. Region edits prepare a guarded new revision and schedule a swap at a safe loop boundary; Stop is immediate. Playback position/name/control follows the actual source or loop. Background jobs pause while loops/export hold PCM, with independent hold reasons; all native decodes remain serialized.
- export-worker.js: complete mono/stereo PCM16, little-endian, actual decoded sample rate; no normalization/resampling/time stretch/pitch shift/dither. Saturation count is reported and saving requires the product UI's acknowledgement when necessary. Prepared WAV and JSON survive share cancellation, become stale after relevant edits, and can be explicitly discarded without deleting musical decisions.

## Sidecar and boundary contract

The sidecar records schema/engine, source identity/fingerprint status, exact end-exclusive frames and seconds, actual decoded rate/channels, PCM16 encoding, requested/actual fades, exact-scope automatic/manual/effective values, grid/reference/tuning choices, preview-only exclusions, saturation and creation time. Local region estimates remain null when only a whole-track tuning/grid reference exists. Filenames remove path separators/control characters and omit unavailable musical values.

Actual sample boundaries are rounded once against the decoded rate. A default 5 ms fade is capped to half the selected duration; >=2-frame fades reach zero at their outside endpoint, and zero fades bypass the envelope. Preview uses the same faded Float32 channels sent to the WAV encoder. Waveform detail displays the original source min/max bins; exported audio uses the displayed selected frame range and actual fade values.

## Resource boundary

M2's default decoded/known-allocation limits remain 128/192 MiB; selected PCM plus its waveform pyramid fits the 16 MiB region-cache budget. Loop AudioBuffer copies and prepared output are accounted as reserved bytes; optional region copies fail cleanly when the combined budget is exceeded. Export bytes remain capped at 64 MiB/RIFF limits; this is an upper ceiling, not a guarantee that every long selection fits the stricter region cache. Select a shorter region or stop the loop when a requested preparation cannot fit. Source playback, corrections and region decisions remain available.

Native decoder/browser/garbage-collection overhead is still unknown. These numeric policies and synthetic checks are not measured phone memory/performance. More channels remain unsupported for analysis/export.
