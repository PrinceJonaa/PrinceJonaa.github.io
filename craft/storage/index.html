How it works

Local-first. Editors continue to save locally in your browser. Press Backup to copy the selected editor files to Drive.

Recoverable. Choose Restore next to a snapshot to download its files back into browser storage.

Permission-limited. Uses the Google Drive drive.file scope: it can access files made by this app, not your whole Drive.

Google configuration

A Google Cloud OAuth Web client is required to connect this public GitHub Pages site. Its client ID is public configuration, not a client secret.

For local testing the client ID is stored only in this browser. To enable it for every visitor, publish it in craft/storage/config.js. Never put an OAuth client secret in this site.

Google Cloud setup steps
  1. Enable Google Drive API in a Google Cloud project.
  2. Configure the OAuth consent screen and include the https://www.googleapis.com/auth/drive.file scope. Add test users while your app is in testing mode.
  3. Create an OAuth Client ID → Web application. Add https://princejona.me as an authorized JavaScript origin (and http://localhost:PORT for local testing).
  4. Paste the public client ID above. Press Connect Google Drive to authorize access.

Google's web token model requires user interaction to reconnect when a token expires; this release supports manual backups, not unattended cloud sync.
