Engineering case / Universe S0–S1

A clear front door.
Room to keep creating.

A shared public catalog and navigation shell that helps people find the tools while preserving local editing contexts.

Explore the catalog →View public source ↗

The context

The Universe contains audio tools, video editors and creative utilities with different runtimes and storage behavior. A public front door needed to make those tools discoverable without loading heavy editor code or interfering with someone’s local project.

My contribution

Public catalog design, shared search, responsive navigation, direct task routes, public-record boundaries and careful editor returns. The discovery pages load small shell modules; editor WASM, ONNX and decoding pipelines stay behind their application routes.

Preserve the workspace

JonaAudio waits for its own metadata writer and refuses a failed save before leaving. RhythmCut opens the Universe in another tab. Craft retains mounted editor frames when a person switches tools or returns to the chooser. Existing origin, service-worker scopes and database names remain in place.

Publish only reviewed records

Search uses explicitly public, published records. Local media, project names, private research and user jobs do not become catalog entries. The shell does not fabricate editor progress.

Recorded release outcomes

  • S0/S1 records 45/45 Node checks: six catalog contracts plus the 39 JonaAudio regressions.
  • Chromium exercised arrow/Enter search, Escape dismissal, a Tab cycle and restored focus, category/status/query/reset controls, URL reload and task routing.
  • Responsive checks at 320, 390, 430, 768, 1200 and 1440 px found no horizontal overflow across the recorded discovery surfaces.
  • Delayed IndexedDB completion and denied-storage cases exercised the JonaAudio metadata writer. Craft switching and RhythmCut return behavior were checked in the browser.
  • Public portrait derivatives preserve the approved images without exposing original EXIF or copying private media.

Attribution & remaining limits

The discovery shell and hosting integration are Prince Jona / Intervised work. LightCraft, FilmCraft and EffectCraft are upstream Storytold editors with their own licenses and release attribution; integrating them is not a claim to author their engines.

The pinned RhythmCut Pages build is 7cd6cb38cdff; the source revision 6d188fc87b46 is newer. This case does not describe those newer changes as live. Physical-device and real-media acceptance remain distinct from responsive browser emulation.
