JonaAudio / Before you begin

Local audio, clear limits.

Your browser does the work

Audio processing runs on your device. Decode support depends on the browser; if a codec fails, try a WAV copy. Large files use more memory.

A session remembers decisions

Saved session metadata does not include the audio. Relink originals when returning. Export session JSON if browser storage is unavailable.

Choose the next measurement

BPM and key are estimates. Engineer and Compare run on demand. You can cancel work and correct results. Stems and real-time pitch correction are planned.
